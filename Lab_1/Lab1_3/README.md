# Лабораторная работа 1.3: метод простых итераций и метод Зейделя

**Вариант:** 18

## 1. Условие задания
Решить систему линейных алгебраических уравнений (СЛАУ) итерационными методами.

**Требования к реализации:**
Необходимо реализовать два итерационных метода: метод простых итераций (Якоби) и метод Зейделя. 

**В результате работы программа должна вывести:**
1. Заданную точность вычислений \(\epsilon\).
2. Количество итераций для каждого метода.
3. Точное или эталонное решение для проверки результата.
4. Сравнение методов по скорости сходимости.

## 2. Вывод результата
Все результаты записываются в текстовый файл **`data/report_lab_1_3.txt`**. В консоль выводится только строка об успешном завершении.

## 3. Структура проекта
```text
Lab1_3/
├── data/
│   ├── matrix_A.txt          # Исходная матрица A
│   ├── vector_b.txt          # Вектор b
│   ├── epsilon.txt           # Заданная точность
│   └── report_lab_1_3.txt    # Итоговый отчет (создается)
└── src/
    ├── main.py               # Точка входа
    ├── utils.py              # Функции чтения матриц/векторов/точности из файлов
    ├── solve.py              # Приведение к эквивалентному виду, методы Якоби и Зейделя
    ├── checks.py             # Проверка условий сходимости
    └── report_utils.py       # Вспомогательные функции для форматирования отчета
```

## 4. Как запустить
1) Перейти в корневую папку лабораторной работы:
```bash
cd ~/Numerical_Methods_5_sem/Lab_1/Lab1_3
```
2) Запустить главный скрипт:
```bash
python src/main.py
```
3) После выполнения открыть файл **`data/report_lab_1_3.txt`** для просмотра отчета.
