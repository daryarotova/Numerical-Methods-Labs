# Лабораторная работа 1.2: Метод прогонки

**Вариант:** 18

## 1. Условие задания
Решить систему линейных алгебраических уравнений (СЛАУ) с трёхдиагональной матрицей методом прогонки. 

**Требования к реализации:**
При реализации **запрещено** хранить всю матрицу (так как она является разреженной). Хранить нужно только значения, лежащие на главной диагонали и двух побочных (векторы \(a, b, c\)), а также вектор правой части (\(d\)).

**В результате работы программа должна вывести:**
1. Все прогоночные коэффициенты (\(P\) и \(Q\)).
2. Итоговое решение системы уравнений (\(x\)).

## 2. Вывод результата
Все результаты записываются в текстовый файл **`data/report_lab_1_2.txt`**. В консоль выводится только строка об успешном завершении.

## 3. Структура проекта
```text
Lab1_2/
├── data/
│   ├── vector_a.txt          # Нижняя диагональ
│   ├── vector_b.txt          # Главная диагональ
│   ├── vector_c.txt          # Верхняя диагональ
│   ├── vector_d.txt          # Вектор правой части
│   └── report_lab_1_2.txt    # Итоговый отчет (создается)
└── src/
    ├── main.py               # Точка входа
    ├── utils.py              # Функции чтения векторов из файлов, их валидация
    ├── sweep.py              # Прямой и обратный ход метода прогонки
    ├── checks.py             # Проверка диагонального преобладания и невязки
    └── report_utils.py       # Вспомогательные функции для форматирования отчета
```

## 4. Как запустить
1) Перейти в корневую папку лабораторной работы:
```bash
cd ~/Numerical_Methods_5_sem/Lab_1/Lab1_2
```
2) Запустить главный скрипт:
```bash
python src/main.py
```
3) После выполнения открыть файл **`data/report_lab_1_2.txt`** для просмотра отчета.
