# Лабораторная работа 1.4: метод вращений Якоби

**Вариант:** 18

## 1. Условие задания
Реализовать метод вращений для численного решения задачи на собственные значения и собственные векторы симметрических матриц.

**Требования к реализации:**
Программа должна принимать на вход симметрическую матрицу и точность вычислений \(\epsilon\). Также необходимо проанализировать зависимость числа итераций от заданной точности.

**В результате работы программа должна вывести:**
1. Заданную точность вычислений \(\epsilon\).
2. Найденные собственные значения.
3. Найденные собственные векторы и матрицу собственных векторов \(V\).
4. Проверку \(A \cdot V = V \cdot \Lambda\), где \(\Lambda\) — диагональная матрица собственных значений.

## 2. Вывод результата
Все результаты записываются в текстовый файл **`data/report_lab_1_4.txt`**. В консоль выводится только строка об успешном завершении.

## 3. Структура проекта
```text
Lab1_4/
├── data/
│   ├── matrix_A.txt          # Исходная симметрическая матрица A
│   ├── epsilon.txt           # Заданная точность
│   └── report_lab_1_4.txt    # Итоговый отчет (создается)
└── src/
    ├── main.py               # Точка входа
    ├── utils.py              # Чтение матрицы и точности, проверка на симметричность
    ├── jacobi_rotation.py    # Реализация метода вращений Якоби
    ├── checks.py             # Проверки A*V = V*Λ и ортогональности V
    └── report_utils.py       # Вспомогательные функции для форматирования отчета
```
