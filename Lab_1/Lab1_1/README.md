# Лабораторная работа 1.1: LU-разложение

**Вариант:** 18

## 1. Условие задания
Методом Гаусса решить систему линейных алгебраических уравнений (СЛАУ).  
Для матрицы СЛАУ вычислить определитель и обратную матрицу.
**Требования к реализации:**
Реализовать алгоритм LU-разложения матрицы с выбором ведущего элемента.

## 2. Вывод результата
Все результаты записываются в текстовый файл **`data/report_lab_1_1.txt`**. В консоль выводится только строка об успешном завершении.

## 3. Структура проекта
```text
Lab1_1/
├── data/
│   ├── matrix_A.txt          # Исходная матрица A
│   ├── vector_b.txt          # Вектор b
│   └── report_lab_1_1.txt    # Итоговый отчет (создается)
└── src/
    ├── main.py               # Точка входа
    ├── utils.py              # Функции чтения матриц/векторов из файлов, их валидация
    ├── lu_decomposition.py   # Реализация LU-разложения
    ├── solve.py              # Решение СЛАУ, нахождение обратной матрицы и определителя
    ├── checks.py             # Функции проверки на корректность
    └── report_utils.py       # Вспомогательные функции для форматирования отчета
```

## 4. Как запустить
1) Перейти в корневую папку лабораторной работы:
```bash
cd ~/Numerical_Methods_5_sem/Lab_1/Lab1_1
```
2) Запустить главный скрипт:
```bash
python src/main.py
```
3) После выполнения открыть файл **`data/report_lab_1_1.txt`** для просмотра отчета.

## 5. Замечание об ответе в задачнике (опечатка)

Было обнаружено расхождение с ответом, указанным в задачнике для варианта 18.

- Ответ в учебнике: `x_book = [-4, 0, -8, -4]`
- Результат программы: `x_my = [-4, 0, -8, 4]`

**Проверка подстановкой:**
Если подставить ответ из учебника в исходную матрицу \(A\), получается вектор `A @ x_book = [-4, -4, -12, 4]`, который не совпадает с исходным вектором правой части \(b = [-20, 60, -60, -44]\).

Если подставить результат программы, получается `A @ x_my = [-20, 60, -60, -44]`, что совпадает с исходным \(b\).

**Вывод:** в задачнике допущена опечатка (разница в знаке последнего элемента). Разработанная программа находит верное решение. Скрипт для проверки этого находится в файле `src/test.py`.
