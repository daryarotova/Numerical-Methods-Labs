# Лабораторная работа 1.5: QR-алгоритм

**Вариант:** 18

## 1. Условие задания
Реализовать алгоритм QR-разложения матриц в виде программы. На его основе разработать программу, реализующую QR-алгоритм решения полной проблемы собственных значений произвольных матриц. Задать в качестве входных данных матрицу и точность вычислений, найти собственные значения.

**Требования к реализации:**
1. Вывести исходную матрицу \(A\), матрицы \(Q\) и \(R\), результат умножения \(Q \cdot R\), а также найденные собственные значения.
2. Привести собственный пример матрицы с комплексно-сопряжёнными собственными значениями и продемонстрировать работу алгоритма для неё.

## 2. Вывод результата
Все результаты записываются в текстовый файл **`data/report_lab_1_5.txt`**. В консоль выводится только строка об успешном завершении.

## 3. Структура проекта
```text
Lab1_5/
├── data/
│   ├── matrix_A.txt          # Исходная матрица A
│   ├── matrix_B_complex.txt  # Матрица B для примера с комплексными числами
│   ├── epsilon.txt           # Заданная точность
│   └── report_lab_1_5.txt    # Итоговый отчет (создается)
└── src/
    ├── main.py               # Точка входа, сборка отчета
    ├── utils.py              # Функции чтения матриц и точности из файлов
    ├── qr_solve_real.py      # QR-разложение, QR-алгоритм для вещественных корней
    ├── qr_solve_complex.py   # QR-алгоритм для матриц с комплексно-сопряженными парами
    ├── checks.py             # Проверки ортогональности Q, треугольности R
    └── report_utils.py       # Вспомогательные функции для форматирования отчета
```

## 4. Как запустить
1) Перейти в корневую папку лабораторной работы:
```bash
cd ~/Numerical_Methods_5_sem/Lab_1/Lab1_5
```
2) Запустить главный скрипт:
```bash
python src/main.py
```
3) После выполнения открыть файл **`data/report_lab_1_5.txt`** для просмотра отчета.
