Лабораторная работа 2.1: Решение нелинейного уравнения

Вариант 18: ln(x+1) - x^3 + 1 = 0
Точность epsilon = 1e-06

--- Проверка начальных приближений ---
          Метод простой итерации
По теореме 2.3: q < 1:
Корень x принадлежит отрезку [1.2, 1.3].
На этом отрезке коэффициент сходимости q = 0.1991 < 1.
Вывод: x0 = 1.2.

          Метод Ньютона
По теореме 2.2: f(x0) * f''(x0) > 0:
При x0 = 1.2: f(1.2) * f''(1.2) = 0.0605 * -7.4066 = -0.4478 < 0 - не подходит
При x0 = 1.3: f(1.3) * f''(1.3) = -0.3641 * -7.9890 = 2.9087 > 0 - подходит
Вывод: x0 = 1.3.
